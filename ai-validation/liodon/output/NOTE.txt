A real run writes here:

    detections.json     detections: class, confidence, bounding box
    annotated.png       input image with boxes drawn on
    run_report.json     timings, memory, providers, hashes

With --input pointing at a folder, each image gets its own subdirectory here so
runs do not overwrite each other.

This directory's contents are git-ignored: they are regenerated by every run, and
keeping them out means `git status` stays clean after you validate locally.

The only file tracked here is this note. Run
    python ai-validation\liodon\scripts\run_liodon.py --input <your-xray>
to populate it.

`_selftest/` is NOT produced by a real run. If it exists, it came from
    python ai-validation\liodon\scripts\selftest_pipeline.py
which uses the SYNTHETIC stand-in graph. That is pipeline plumbing evidence and
has nothing to do with the Liodon model.
