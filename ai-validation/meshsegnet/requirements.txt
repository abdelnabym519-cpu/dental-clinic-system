# The ordinary PyPI torch wheel for Linux pulls in ~2 GB of unused CUDA
# runtime libraries; the CPU index avoids that.
#

# The official project pins numpy 1.23.1; 1.26.4 is used here and works.

# Optional — memory reporting on Windows.
#
# run_meshsegnet.py prints one RAM line and records a RAM field. That is
# diagnostics only and has no effect on inference. Measurement goes through the
# first probe that works: psutil, then the Windows GetProcessMemoryInfo API via
# ctypes, then the POSIX resource//proc probes.
#
# psutil is NOT required: without it on Windows the ctypes probe still reports
# the working set and peak working set, and if no probe works the field reads
# "n/a (probe unavailable)". Install it only if you want psutil's numbers.
#
